# dAIly

今日をほどいて、明日を少し好きになるためのAI日記です。

1日の終わりに次の3つを記録します。

- **DETOX** — 頭の中のモヤモヤ
- **GOOD** — その日の自分の良かった点
- **MOTTO** — 明日を良くするための小さな一歩

入力内容をもとに、AIが具体的な称賛と前向きな視点、明日への実行しやすい提案を返します。日記とAIの言葉は日付ごとにブラウザへ保存され、カレンダーから振り返れます。

3日分以上の日記が集まると「成長」画面から、直近最大30件をもとにした成長レポートを作成できます。記録に書かれた事実を根拠として、積み重なっている強み、小さな変化、繰り返し現れるテーマ、次の焦点を確認できます。

## 開発環境

```bash
npm install
copy .env.example .env.local
npm run dev
```

ブラウザで `http://localhost:3000` を開いてください。

`OPENAI_API_KEY` が未設定の場合は、画面確認用のデモ応答が返ります。APIキーは `.env.local` のみに保存し、Gitへコミットしないでください。

## 技術構成

- Next.js / React / TypeScript
- Tailwind CSS
- OpenAI Responses API
- Zod
- Local Storage（初期MVPの日記保存）

## プライバシー

日記データは初期版では使用中のブラウザに保存されます。AI応答の生成時のみ、入力した3項目がサーバー経由でOpenAI APIへ送信されます。APIリクエストでは `store: false` を指定しています。
